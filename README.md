# Проект "Stellar Burger"
Проект представляет интернет-магазин бургеров. При работе над ним моей целью было освоение Redux, React Route, а также приобретение опыта написания тестов на Cypress и Jest.

## Что сделано
* Тесты на Cypress для страницы конструктора бургера
* Тесты на Jest для страницы конструктора бургера
* Редактор данных пользователя
* В шапке панели навигации активна та ссылка на маршрут, где сейчас находится пользователь
* При клике на пункт «История заказов» происходит переход на экран /profile/orders , ссылка «История заказов» становится активной
* При клике по ингредиенту происходит переход на маршрут /ingredients/:id и открывается модальное окно с описанием ингредиента. При прямом переходе на этот маршрут открывается страница с информацией об ингредиенте.
* Заказы могут делать только авторизованные пользователи, все остальные действия доступны и неавторизованным.
* Экран «Лента заказов» отображается по маршруту /feed , доступен всем пользователям.
* Экран «Лента заказов» обновляется в режиме реального времени, когда авторизованный пользователь создаёт заказ. Содержит подсчёт стоимости каждого заказа, исходя из стоимости его ингредиентов.
* Экран «Лента заказов» отображает количество всех заказов, а также количество заказов за день.
* Экран «История заказов» отображается по маршруту /profile/orders , доступен только авторизованным пользователям.
* Экран «История заказов» обновляется в режиме реального времени и отображает статусы заказов.
* Экран «История заказов» содержит подсчёт стоимости каждого заказа, исходя из стоимости его ингредиентов. Статусы «Отменён», «Готовится» и «Выполнен» формируются в зависимости от значения поля status каждого заказа.
* При клике по заказу открывается модальное окно с информацией о заказе и происходит переход на маршрут /feed/:number или /profile/orders/:number. При прямом переходе на эти маршруты открывается страница заказа.
* Маршрут /profile/orders/:number доступен только авторизованным пользователям.

## Реализованный функционал
* Добавление и удаление ингредиентов из корзины
* Авторизация и регистрация пользователя
* Лента заказов других пользователей
* История заказов пользователя
* Открытие и закрытие модальных окон
* Оформление заказа

## Технологии
* HTML, SCSS, TypeScript, React, React Route, Redux, Webpack, Cypress, Jest
  
## Инструкция по запуску
1. Создать папку и перейти в нее
2. Клонировать этот репозиторий
```
git clone https://github.com/Catherine1563/stellar-burgers.git
```
4. Установить все зависимости
```
npm install
```
5. Установите зависимость:
```
npm install dotenv
```
6. Создать папку .env и добавить в нее:
```
BURGER_API_URL = https://norma.nomoreparties.space/api
```
7. Запустить проект
```
npm run start
```
Для запуска тестов на Jest
```
npm run test
```
Для запуска тестов на Cypress
```
npm run cypress:open
```

## Системные требования
Для запуска потребуются Node.js
